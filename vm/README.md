## Installation instructions

On Linux, the VM can be run from the Virtual Machine Manager app: https://virt-manager.org/

On MacOS the VM can be run using the UTM app: https://mac.getutm.app/

On Windows the VM can be run using QEMU on windows: www.qemu.org/download/#windows
